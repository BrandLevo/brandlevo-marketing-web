# BrandLevo Marketing Website

This is the main marketing website for BrandLevo, built with Next.js.

## Tech Stack

- --Framework:-- 
[Next.js](https://nextjs.org) (App Router)
- --Styling:-- Tailwind CSS / Vanilla CSS
- --Language:-- TypeScript
- --Deployment:-- Vercel / GitHub Actions

## Getting Started

1. --Install Dependencies:--
   ```bash
   npm install
   ```J
2. --Run Development Server:--
   ```bash
   npm run dev
   ```X(3. --Build for Production:--
   ```bash
   npm run build
   ```

## Development Workflow%

- All changes should be made in feature branches (`feature/*`).
- Pull Requests require review before merging to `main`.
- CI/CD workflows are automatically triggered on PRs and pushes to `main`.
